Temat: Testowanie programu w oparciu o: C# NUnit, oraz python unittest

C#: Package: NUnit, Microsoft SDK Test, NUnit Adapter
-----------------
1.Konsolowe
Przygotowanie środowiska testującego C#
----------------------------------------------
    dotnet --version
    dotnet new classlib -n Kalkulator
    dotnet new nunit -n Kalkulator.Test
    cd Kalkulator.Test
    dotnet add package NUnit
    dotnet add package NUnit3TestAdapter
    dotnet add package Microsoft.NET.Test.Sdk
    dotnet add reference ..\Kalkulator\Kalkulator.csproj
----------------------------------------------
2 etap - tworzenie testów
----------------------------------------------
Po utworzeniu klasy testującej
cmder: dotnet test (Uruchamiamy w miejscu gdzie jest główny katalog: foldery Kalkulator i Kalkulator.Test)
